# Admin Dashboard

A responsive admin dashboard built with pure HTML and CSS. Features a sidebar navigation, top navbar with search and user profile, project cards, announcements panel, and a trending section.

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox)

## Features
- Sidebar navigation with icons
- Search bar and user profile in navbar
- Project cards with action icons
- Announcements and trending panels
- Responsive grid layout
